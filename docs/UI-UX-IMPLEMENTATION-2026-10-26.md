# Corterm Mobile 体验优化实施与验收

日期：2026-10-26。对应审查：[UI/UX 审查与可行性复核](UI-UX-AUDIT-2026-10-26.md)。范围为本轮 Flutter 客户端和文件恢复所需 Gateway/Worker 实现，未发布到生产或应用商店。

## 完成结果

- Duo 原生工具栏负责当前页面操作，一级标签负责工作区、电脑、我的；内容中的工作区目录允许手动折叠。折叠不撤销 Navigator、不重建终端连接，也不隐藏系统工具栏或标签。
- 目录状态持久化；宽屏收起后保留 48pt 明确入口，窄屏按空间退化。显式折叠区域仍约束内容，不能因为隐藏目录就跨越不可用区域。消除收起时重复出现的抽屉按钮。
- 首页突出在线会话的“继续会话”；目录提供工作区内新建会话。创建缺少电脑、工作区、电脑离线或原工作区失效时，分别提供配对、创建、查看电脑和重选入口。
- 搜索独立呈现三个数据来源的加载和错误，保留可用结果、只重试失败来源，并增加范围说明、清空和账号隔离的最近搜索。
- 表单提交期间防重复，失败留住输入；个人资料和终端主题离开时保护未保存修改。共享弹层有明确边界、可滚动、处理键盘遮挡；确认操作关闭其所属弹层。
- 文件支持传输阶段、字节进度、取消、冲突确认；协议切换显式反馈。文本严格按 UTF-8 解码，支持查找、复制、只读/大小说明；不支持和超限类型不会自动整文件下载。
- 普通文件删除改为移到工作区回收目录；本机保存恢复凭据，提供“最近删除”。恢复拒绝覆盖已有目标。Gateway、Worker、客户端三端配套实现，未调用旧接口永久删除作为降级。
- 偏好支持终端按键选择和排序、恢复本地默认设置；主题支持当前选择、自定义增改删、终端字符预览、对比度提醒和颜色语义标签。
- 反馈文本草稿按账号保存；上传成功的附件在当前页面重试时复用。诊断显示检查时间、可读结论、可展开详情和不包含令牌/终端输出的复制摘要。
- 修复原生终端输入中累计编辑值被反复提交的问题，包括中文组合、粘贴、删除、重复平台回调与回车边界。实际 TerminalView 回调和模拟器远端命令均验证。
- 修复原生工具栏类型化菜单回调的运行时错误；此前菜单可展开但选择文件等动作不执行。新增直接调用适配后菜单动作的回归用例，修复后在模拟器检查实际导航。
- 修复文件变更接口返回空 HTTP 200 时被误判为 JSON 错误，以及文件刷新把 Future 返回给 setState 回调的问题。

## 回收/恢复契约与上线边界

- 客户端先持久化随机 32 位十六进制恢复 ID、原路径和待确认状态，再发送请求；响应丢失时凭据不会随页面关闭消失。记录按网关、账号、工作区隔离。
- Worker 将文件或整目录移动到 `.corterm-trash/<receipt>/payload`，保存原路径清单与管理标记。拒绝工作区根、回收存储自身、无效 ID、未受管理的同名回收目录与恢复目标冲突。重复移动相同有效凭据是幂等操作。
- 恢复不覆盖同名文件，原父目录不存在时明确失败。失败保持凭据和远端文件。没有自动清理或过期销毁。
- 记录索引保存在发起设备，未实现跨设备回收目录同步；卸载或清除本机数据会丢失索引，远端回收内容仍存在。不能称为云端全量回收站。
- Gateway 新增 authenticated POST `files/trash` 和 `files/restore`，验证工作区归属并调用 Worker RPC。部署必须同时更新 Gateway 和 Worker；本轮没有部署这些接口到线上。旧服务不支持时明确失败，绝不偷偷调用永久 delete。
- 远端路径沿用项目当前的符号链接策略；本轮针对回收存储额外拒绝符号链接，但没有宣称实现整个远端文件系统的符号链接隔离。
- 本轮远端回收使用临时目录自动化验证，没有删除真实用户文件来试验。
