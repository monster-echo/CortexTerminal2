# Corterm 移动端新建流程设计

> 本文档补充 Corterm Flutter 移动端的“新建”相关流程，统一定义 **新建工作区**、**新建电脑**、**新建会话** 三条路径，以及工作区文件夹选择页面的交互方式。本文档在 `design/mobile-workspace-ui.md` 的基础上生效，若有冲突，以本文档为准。

## 1. 设计目标

移动端所有“新建”入口必须做到：

- 入口清晰：用户从哪里点击，就进入对应对象的创建页面。
- 页面单一：一个页面只负责创建一个对象。
- 上下文明确：创建页尽量继承当前上下文，不再让用户做多余判断。
- 视觉统一：继续遵循 ChatGPT Mobile Light 风格，使用白底、浅灰 Surface、大圆角和弱边框。

## 2. 新建入口规则

### 2.1 工作区页顶部 `+`

入口：

```text
首页 → 工作区 Tab → 右上角 +
```

行为：

- 直接进入 **新建工作区** 页面。
- 不弹菜单。
- 不先弹 Bottom Sheet。

### 2.2 电脑页顶部 `+`

入口：

```text
首页 → 电脑 Tab → 右上角 +
```

行为：

- 直接进入 **新建电脑** 页面。
- 不弹菜单。
- 不先弹 Bottom Sheet。

### 2.3 侧边栏底部「新建」

入口：

```text
侧边栏底部 → 新建
```

行为：

- 直接进入 **新建会话** 页面。
- 不再弹统一“新建菜单”。
- 该入口专门用于会话创建。

### 2.4 Workspace 内部「新建会话」

入口：

```text
Workspace 详情页 → 新建会话
```

行为：

- 进入 **新建会话** 页面。
- 当前 Workspace 自动带入。
- 会话与该 Workspace 绑定。

## 3. 新建工作区

### 3.1 页面作用

“新建工作区”用于：

- 选择一台已连接电脑
- 选择该电脑上的远端文件夹
- 自动生成工作区名称
- 创建新的 Workspace

### 3.2 页面结构

```text
新建工作区

电脑
Mac mini                               ›

文件夹
~/Projects/CortexTerminal2             ›

名称
CortexTerminal2

[ 创建工作区 ]
```

### 3.3 字段规则

#### 电脑

- 必填。
- 点击后进入电脑选择页或选择列表。
- 只能选择已成功配对的电脑。

#### 文件夹

- 必填。
- 不能直接内嵌复杂目录树。
- 点击后进入独立的 **选择文件夹** 页面。
- 选择完成后返回，并将所选路径回填到“文件夹”字段。

#### 名称

- 默认根据所选文件夹的 basename 自动生成。
- 用户可以手动修改。
- 示例：选择 `~/Projects/CortexTerminal2` 后，名称自动为 `CortexTerminal2`。

### 3.4 创建按钮

- 底部主按钮为黑底白字：`创建工作区`
- 只有在“电脑”和“文件夹”都有效时可点击。

## 4. 选择文件夹（独立页面）

### 4.1 页面定位

“选择文件夹”是一个独立页面，不嵌在“新建工作区”主页面内。

进入方式：

```text
新建工作区 → 点击“文件夹”字段 → 进入选择文件夹页面
```

### 4.2 页面结构

```text
选择文件夹

电脑
Mac mini

当前位置
~/Projects

文件夹
CortexTerminal2                       ✓
AI-MIDI                               ›
MV2                                   ›
Geekread                              ›
FieldTrust                            ›

[ 使用此文件夹 ]
```

### 4.3 行为规则

- 顶部展示当前选择的电脑。
- 页面显示当前浏览路径。
- 仅展示文件夹，不展示普通文件。
- 点击某个文件夹：
  - 若进入下一层，则进入该子目录。
  - 当前正在选中的文件夹显示选中状态。
- 点击底部 `使用此文件夹`：
  - 返回“新建工作区”页面。
  - 将所选路径写入“文件夹”字段。
  - 自动更新“名称”字段默认值。

### 4.4 视觉规则

- 使用列表式结构，不做复杂树控件。
- 选中项使用轻灰背景 + 选中符号。
- 保持白底、浅灰卡片、黑色主按钮的整体风格。

## 5. 新建电脑

### 5.1 页面作用

“新建电脑”用于将手机与一台安装了 Corterm Worker 的电脑建立配对关系。

### 5.2 页面结构

```text
新建电脑

[ 扫码区域 ]
扫描电脑端 Corterm 显示的二维码

—— 或 ——

输入配对码                           ›

配对成功后可继续创建工作区。

[ 开始扫描 ]
```

### 5.3 行为规则

- 主路径是扫码配对。
- 备选路径是手动输入配对码。
- 成功后该电脑会进入“电脑”列表。
- 配对成功后可继续进入“新建工作区”流程。

### 5.4 禁止事项

“新建电脑”不能设计成以下形式：

- SSH 表单
- RDP 表单
- 主机地址 / 端口 / 用户名 / 密码录入页

原因：当前产品真实逻辑是 **Worker 配对**，不是通用远程协议手工配置。

## 6. 新建会话

### 6.1 页面作用

“新建会话”用于创建一个与某个 Workspace 绑定的会话。

### 6.2 核心规则

- **新建会话页面不显示“类型”选择。**
- 页面主要选择：
  - 电脑
  - 工作区
- 当前选择的 Workspace 决定该会话的工作上下文。

### 6.3 页面结构

```text
新建会话

电脑
Mac mini                               ›

工作区
CortexTerminal2                        ›

名称（可选）
新会话

所选工作区将绑定到此会话，决定会话的上下文和可访问文件。

[ 创建会话 ]
```

### 6.4 选择规则

#### 从侧边栏底部「新建」进入

- 需要用户选择：
  - 电脑
  - 工作区
- 名称为可选项。

#### 从 Workspace 内部进入

- 当前 Workspace 自动带入。
- 电脑也可根据该 Workspace 自动推断。
- 工作区字段可以显示，但默认已选中当前 Workspace。
- 会话创建后自动绑定该 Workspace。

### 6.5 名称规则

- 名称为可选。
- 默认值可为：`新会话`
- 用户也可以不填写，由系统使用默认命名策略。

### 6.6 会话绑定说明

文案应明确说明：

> 所选工作区将绑定到此会话，决定会话的上下文和可访问的文件。

这可以帮助用户理解：会话不是孤立存在，而是属于某个 Workspace。

## 7. 页面拆分规则

设计图和实现文档都要遵循：

- 一个功能一个页面图
- 不再使用“一张大图包含所有流程”的展示方式
- 每张图保持移动端真实页面比例
- 每个页面单独说明用途和交互

当前应拆分为至少以下独立页面：

1. 新建工作区
2. 选择文件夹
3. 新建电脑
4. 新建会话

## 8. 与已有文档的关系

本文档对以下已有规则进行补充或修正：

### 8.1 对 `mobile-workspace-ui.md` 的补充

补充：

- “文件夹浏览”必须是独立页面。
- 顶部 `+` 行为直接进入对应创建页。
- 侧边栏「新建」只进入新建会话。

### 8.2 对旧“统一新建菜单”思路的修正

不再采用：

```text
新建
├─ 新建电脑
├─ 新建工作区
└─ 新建会话
```

这种统一菜单作为唯一入口的方式。

新的规则是：

- 顶部 `+` = 新建当前页面对应的对象
- 侧边栏底部「新建」 = 新建会话

## 9. 当前确认版本

当前版本已确认以下设计决策：

- 工作区页右上角 `+` 直接进入新建工作区。
- 电脑页右上角 `+` 直接进入新建电脑。
- 侧边栏底部「新建」直接进入新建会话。
- 新建会话不显示“类型”。
- 新建会话以选择电脑、选择工作区为主。
- Workspace 内部发起的新建会话自动绑定当前 Workspace。
- 新建工作区时必须有文件夹浏览能力。
- 文件夹浏览是独立页面。
- 点击“文件夹”字段进入“选择文件夹”页面。
- 所有页面单独设计、单独出图、保持移动端页面比例。
